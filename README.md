A fork of Convenient Name Tags, updating it to modern versions and adding some conveniences.

## Installation

Toil and Trouble is a client and server mod for Fabric 1.21.1. Its dependencies are listed below.

#### Dependencies
- [Fabric API](https://modrinth.com/mod/fabric-api) is required on Fabric Loader.
- [McQoy](https://modrinth.com/mod/mcqoy) is recommended to configure the mod.

## Features

- Anvils are no longer required to rename a name tag. Just right click with the name tag, and a screen will open allowing the name tag to be rena,ed. 

## FAQ

- Will this mod be ported to other versions/loaders?
  - The mod actively supports the latest version of Minecraft (currently 26.1). There is no plan to backport to older versions, please use the original mod.
